# Spotlight Rules — removed

Spotlight Rules was Kin Lane's own project, an earlier fork of Stoplight Spectral. It has been
retired and replaced by [OpenLint](https://openlint.org). Its npm organization, the
spotlight-rules.com domain and most of its repositories are gone.

On 2026-10-23 Kin Lane (owner) asked for the project to be removed entirely from the API
Evangelist network and the APIs.io catalog. That was honored in full: the `apis.yml` and every
artifact in this repository were deleted, and its provider, API and artifact pages were taken
down from apis.io and apievangelist.com. Nothing about it remains published.

The slug `spotlight-rules` (and the earlier `api-evangelist-spotlight-rules`) is on the
delisting registry (`api-search/network/_data/delisted.yml`), so no harvest or enrichment
pipeline will re-add it.

Questions or removal requests: info@apievangelist.com
